## 验证结论

1. 两个入口都走通：设置页口令门禁、遮罩上按菜单键后的口令面板。
2. 旧码重放被拒：`恢复码不正确`（作废生效）。
3. 校验位提示：单点改错 → `末位对不上，检查是否抄错或按错`，而不是笼统报错。
4. 成功路径落盘一致：`phase=0`、新 `pinHash`、新 `rcHash`、`rcSaved=true`；
   遮罩路径下会话按「已结束」处理（`pin ok -> exit session`）。

## 过程中修掉的两个真机缺陷

- **浮层焦点逃逸**：口令面板盖住设置页，但焦点能掉到面板背后，再按 OK 会误触「开始计时」。
  本目录第一轮采集时 logcat 里真的出现了 `action=app.quizgate.tv.START`。
  已改为每层浮层把下层设为 `FOCUS_BLOCK_DESCENDANTS`，只留最上面一层吃焦点。
- **返回语义**：设置页点「家长口令」再按返回，`onPinCancel` 无条件 `finish()`，把整个设置页关了。
  已改为只有「首次必须设口令」的门禁才退出，其余情况回设置页。
