# 恢复路径

三种会把用户困住的情况，以及怎么出来。

## 1. 忘口令

**现状（v1.0.0）：没有恢复码。**

| 步骤 | 做法 | 代价 |
| --- | --- | --- |
| 1 | 卸载应用（设置里卸载，或 `adb uninstall app.quizgate.tv`） | 设置、口令、题库状态全部丢失（`allowBackup=false`） |
| 2 | 重新安装并重新设置 | 电视恢复原样，无残留 |

我们**故意不做**「隐藏后门」：任何不依赖口令的自助通道，孩子也能用。
恢复码（首次设置时生成、家长拍照保存）是下一版计划项。

## 2. 遮罩卡死（画面在，按键无响应）

按顺序试：

1. **长按 OK 10 秒** → 触发窗口重建（`remove` + `add` 同一个 View）
2. **按电源键熄屏 10 秒，再按一次唤醒** → 触发 `reconcile`，多数焦点问题会自愈
3. **拔电源重启** → 重启后若 `phase=LOCKED`，遮罩会重新弹出
4. **仍不行** → `adb shell am force-stop app.quizgate.tv`，再打开应用

> 注意：按电源键会触发小米的 `killAllThirdApp`，但通知监听会在约 150ms 内把进程拉回来，
> 所以第 2 步不会让守护消失。

## 3. 开机循环

v1.0.0 **尚未实现崩溃熔断**。如果遇到开机就崩：

1. 立刻执行 `adb shell am force-stop app.quizgate.tv` 阻止继续启动
2. 导出日志：`adb logcat -d -s AndroidRuntime:E > crash.txt`
3. 提 issue 附日志
4. 应急：`adb uninstall app.quizgate.tv`，电视恢复正常

计划中的 SAFE 模式：连续 3 次异常启动后不再挂遮罩，只显示诊断页，
保证「最坏情况是没守护，不是电视不能用」。

## 4. 家长想立刻放行

| 场景 | 做法 |
| --- | --- |
| 会话中想结束 | 遮罩上按**菜单键** → 输 6 位口令 |
| 已经有会话在跑，想改设置 | 先结束会话；设置页本身也要口令 |
| 孩子正在看，家长要临时接管 | 菜单键 + 口令，等同于结束会话 |

## 5. 孩子试图绕过时会发生什么

| 动作 | 结果 |
| --- | --- |
| 按 HOME | 遮罩仍在最上层，且保持焦点 |
| 按 BACK | 被吞掉 |
| 按电源键 | 应用被强停，但 150ms 后被系统重新拉起，计时继续 |
| 设置里强行停止 | 同上 |
| 重启电视 | 进程被系统拉起，会话按快照续时 |
| 卸载 | **成功**。这是 Android 的设计，防不住 |
| 用手机/平板看 | 与本应用无关，不防 |
