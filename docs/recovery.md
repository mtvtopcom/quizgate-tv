# 恢复路径

三种会把用户困住的情况，以及怎么出来。

## 1. 忘口令

**v1.1.0 起有恢复码**，不用再卸载。

| 步骤 | 做法 |
| --- | --- |
| 1 | 找出拍照留下的那张纸/照片（首次设置口令后会自动展示；也可随时在设置 → 恢复码 里重新生成） |
| 2 | 输入 8 位数字，4-4 分组。末位是校验位——抄错/按错会当场提示「末位对不上」，而不是笼统报错 |
| 3 | 设置新的 6 位口令（输两次确认） |
| 4 | 电视给出**新的**恢复码，重新拍照。旧码在你确认新口令的同一刻作废 |

入口有两个，都在家长侧：

- 设置页的口令门禁 → 「忘记口令？用恢复码重置」
- 遮罩上按**菜单键** → 口令面板 → 同一个入口（孩子正在看时也能当场救）

细节：

- 错 5 次锁 30 分钟。试错计数与口令**完全独立**，孩子乱输恢复码不会把家长的口令一起锁死。
- 恢复成功 = 家长接管：当前会话按「已结束」处理，**不保留剩余时间**（否则猜到码就是免费续杯）。
- 应用里只存 PBKDF2 哈希，看不到已生成的码。想再看只能重新生成，旧码立即失效——所以设置页那行
  在你点过「我已拍照保存」之前会一直显示「待拍照」。

### 恢复码也丢了怎么办

只能卸载重装：电视设置里卸载，或 `adb uninstall app.quizgate.tv`。设置、口令、题库状态全部丢失
（`allowBackup=false`），电视恢复原样。

重装后是**全新机器状态**：打开就是「设置 6 位家长口令」，不会沿用旧口令（应用里没有默认口令，
也不从备份恢复）。付完这个代价，旧口令和旧恢复码就都作废了。

这就是恢复码的边界：它把「忘口令 = 必然丢数据」降成「照过照片就能救」，不是 100%。

### 为什么不用手机扫码 / 局域网

那需要 `INTERNET` 权限，会摧毁「无网络权限」这条可被 `apkanalyzer manifest permissions` 验证的
结构性事实（见 README「它不做什么」第 4 条）。为一个一年用一次的流程不值当。

### 为什么不给你一个短的「万能码」

任何不依赖凭据的自助通道，孩子也能用。恢复码是 8 位数字 + 限流的组合，不是后门：它需要一张
家长才有的照片。

## 2. 遮罩卡死（画面在，按键无响应）

按顺序试：

1. **长按 OK 10 秒** → 触发窗口重建（`remove` + `add` 同一个 View）
2. **按电源键熄屏 10 秒，再按一次唤醒** → 触发 `reconcile`，多数焦点问题会自愈
3. **拔电源重启** → 重启后若 `phase=LOCKED`，遮罩会重新弹出
4. **仍不行** → `adb shell am force-stop app.quizgate.tv`，再打开应用

> 注意：按电源键会触发小米的 `killAllThirdApp`，但通知监听会在约 150ms 内把进程拉回来，
> 所以第 2 步不会让守护消失。

## 3. 开机循环

v1.2.0 起有**崩溃熔断**（ADR-8）。连续 3 次启动崩溃后：

- 不再挂遮罩，服务返回 `START_NOT_STICKY`，重启循环停止（不是「只不显示窗口」——那样还会一直闪）
- 首页顶部出现红色横幅，设置页「守护状态」显示「已停止（安全模式）」
- 点横幅或那一行，能看到最后一次崩溃的根因，并按「恢复守护」重新开始

**恢复后如果又连续崩 3 次，会重新熔断。** 这说明有个稳定的崩溃点，请把那行崩溃信息反馈出来。

想立刻止住循环（连应用都进不去时）：

```bash
# 停掉进程，循环立刻中断
adb shell am force-stop app.quizgate.tv
```

如果连应用都打不开（说明崩在更早的初始化阶段，熔断横幅也看不到），只能清数据：

```bash
# 清空设置、口令、题库进度，回到首次安装状态（应用本身保留，不用重装）
adb shell pm clear app.quizgate.tv
```

兜底手段不变：

1. `adb shell am force-stop app.quizgate.tv`
2. 导出日志：`adb logcat -d -s AndroidRuntime:E > crash.txt`
3. 提 issue 附日志
4. 最后的应急：`adb uninstall app.quizgate.tv`，电视恢复正常（设置与题库状态会丢）

## 4. 家长想立刻放行

| 场景 | 做法 |
| --- | --- |
| 会话中想结束 | 遮罩上按**菜单键** → 输 6 位口令 |
| 已经有会话在跑，想改设置 | 先结束会话；设置页本身也要口令 |
| 孩子正在看，家长要临时接管 | 菜单键 + 口令，等同于结束会话 |

## 5. 孩子试图绕过时会发生什么

| 动作 | 结果 |
| --- | --- |
| 按 HOME | 遮罩仍在最上层，且保持焦点 |
| 按 BACK | 被吞掉 |
| 按电源键 | 应用被强停，但 150ms 后被系统重新拉起，计时继续 |
| 设置里强行停止 | 同上 |
| 重启电视 | 进程被系统拉起，会话按快照续时 |
| 卸载 | **成功**。这是 Android 的设计，防不住 |
| 用手机/平板看 | 与本应用无关，不防 |
