# 自定义题库上传说明

不用装任何软件。电脑或手机上整理题目 → 手机扫码 → 传到电视。

题目格式采用开源项目 [K12 题库工厂](https://github.com/mtvtopcom/k12-question-bank)
的标准（MIT），用它的工具批量生成的题可以直接导入。字段含义见
[bank-format.md](bank-format.md)。下面只讲**怎么把题填出来**。

## 一、整理题目

三种格式任选一种。

### 格式 A：Excel / CSV（题目多时最好用）

第一行是表头，**列顺序不限**。最少填这 8 列：

| grade | subject | stem | option_a | option_b | option_c | option_d | answer |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 3 | 数学 | 48 ÷ 6 = ? | 6 | 7 | 8 | 9 | C |

- `grade`：`1`–`9`，或 `一年级`…`九年级`，或 `初一`…`初三`
- `subject`：`语文` / `数学` / `英语`（也认 `chinese` / `math` / `english`）
- `answer`：`A` / `B` / `C` / `D`
- 想补解析和难度就加列：`explanation`（解析）、`difficulty`（1–4）、
  `bloom`（记忆/理解/应用/分析/评价/创造）
- **用 K12 题库工厂导出的 12 列也能直接传**：那套表里有 `topic_id` 和
  `topic_name`，没有 `grade`/`subject`——年级科目会自动从 `topic_id`
  （如 `primary-g3-s1-math-K018`）推出来，不用你补。

存成 `.xlsx`、`.xls`、`.csv` 都行。CSV 的编码不用管，UTF-8 和 Windows 的 GBK 都能识别。

### 格式 B：txt（手打、从网页复制时最方便）

一题一段，段与段之间**空一行**，字段用 `【】` 开头：

```
【年级】三年级
【科目】数学
【题干】48 除以 6 等于多少？
【选项】A. 6　B. 7　C. 8　D. 9
【答案】C
【解析】六八四十八

【年级】三年级
【科目】数学
【题干】1 米等于多少厘米？
【选项】A. 10 厘米　B. 100 厘米　C. 1000 厘米　D. 10000 厘米
【答案】B
【解析】1 米 = 100 厘米
```

规则只有四条：

1. 每题写 `【年级】` 和 `【科目】`（这是给手写加的标签，K12 标准里没有，
   标准格式靠 `topic_id` 推）。不写也行，但导入时会报「年级/科目无法确定」。
2. `【选项】` 写一行或分行都可以，用 `A.` `B.` `C.` `D.` 开头。
3. `【答案】` 写 A / B / C / D。
4. `【解析】` `【难度】` 可省略；题与题之间必须空一行。

保存时编码选 UTF-8（记事本默认即可）。

### 格式 C：JSON（给会写程序的人 / 上游工具生成）

可以是 K12 标准的顶层数组：

```json
[{"topic_id":"primary-g3-s1-math-K018","topic_name":"长方形、正方形的特征与周长",
  "stem":"长 8 米、宽 5 米，绕一圈多少米？","options":["26 米","13 米","40 米","21 米"],
  "answer":"A","explanation":"(8+5)×2=26 米。","difficulty":2,"bloom":"应用",
  "type":"single_choice"}]
```

也兼容本项目旧格式：

```json
{"questions":[{"subject":"数学","grade":1,"stem":"1+1等于几？","options":["1","2","3","4"],"answerIndex":1,"explanation":""}]}
```

### 旧格式还能用吗

能。表头「年级、科目、题干、A、B、C、D、答案、解析」、`# 一年级 数学` 开头的
三段式 txt、数字 0–3 的答案，都继续支持，历史文件不用改写。

### 幼儿园的题

本软件只有 1–9 年级，`topic_id` 以 `kg-` 开头（或年级写「幼儿园」）的题会被
**跳过并提示数量**，不会硬塞进一年级。

## 二、传到电视

1. 电视上：`设置 → 题库管理 → ＋ 添加题库`
2. 手机相机或浏览器扫电视上的二维码
3. 网页里填题库名（默认用文件名）、选文件、点「开始导入」
4. 看到「导入成功，共 N 题」就好了，电视上的列表会自动刷新

**手机和电视必须连同一个 WiFi。** 微信扫码提示「非官方网页」时选「继续访问」。

上传只在手机和电视之间直连，题目不会经过任何外部服务器。

## 三、新建还是合并

上传页有两个选项：

- **新建一个题库**：这次上传的题目单独成一个题库
- **合并到已有题库**：追加到某个已有题库，重复题目按题干自动跳过

题库名和已有题库重名时，即使选的是「新建」，也会自动合并到那个题库并排重，不会再建一个同名库。
上传完成后手机和电视都会显示结果：新增多少题、重复跳过多少题、题库现在共多少题。

默认题库不能合并，也不能删除。

## 四、选择与删除

- 在题库管理里把光标移到某个题库，按 OK 会弹出「使用这个题库 / 删除这个题库 / 取消」
- 删除要在这个面板里再确认一次，删掉后不能恢复；正在用的题库被删会自动切回默认题库
- 切换题库后会弹出「题库已切换」提示，可以顺着提示重新设置题目年级
- 删除题库不影响默认题库；用户题库存在应用私有目录，覆盖升级保留，卸载应用才清除
- 页面最下方是「＋ 添加题库」和「← 返回上一级」两个按钮

## 五、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 手机打不开二维码地址 | 手机用了移动数据，或路由器开了 AP 隔离 | 连同一个 WiFi；在路由器里关掉「AP 隔离 / 客户端隔离」 |
| 提示「没有解析出题目」 | 表头名字不对，或 txt 没有空行分段 | 照上面的模板检查表头与空行 |
| 提示「第 N 题：答案必须是 A/B/C/D」 | 答案列写了汉字或空着 | 改成 A/B/C/D |
| CSV 中文乱码 | Excel 存成了 GBK | 程序会自动兼容 GBK；仍有问题时另存为「CSV UTF-8」 |
| 上传成功但答题没变化 | 没有切换题库 | 回题库管理选中新题库并确认 |
| 题库里没有当前年级的题 | 只传了部分年级 | 会自动用默认题库出题，遮罩顶部提示一次 |

## 六、题目数量建议

| 单个题库题量 | 建议 |
| --- | --- |
| 几十到几千 | 直接传，电视加载一片只要几毫秒 |
| 一万到三万 | 可以传，按年级科目分片存储，只加载用到的部分 |
| 三万以上 | 建议拆成多个题库，或等后续版本换成 SQLite 存储 |

单次上传上限 30000 题，单个题库上限 100000 题，请求体上限 40MB。
