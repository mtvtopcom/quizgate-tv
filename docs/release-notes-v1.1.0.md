## 新增：离线恢复码

以前忘 6 位口令，唯一出路是卸载重装——设置全丢。现在不用了。

**怎么拿到**：首次设完口令后，界面会立刻显示一枚 **8 位数字**（4-4 分组），拍照存起来。应用只存哈希，之后再也看不到明文，所以**必须当场保存**。

**怎么用**：

1. 口令界面按「忘记口令？用恢复码重置」
2. 输入 8 位数字（输错一位会当场提示「末位对不上」，不会笼统报错，也不会清空你已输的内容）
3. 设新口令 → 系统给一枚新恢复码，**旧码立即作废**

设计上的三个细节：

- **旧码作废和新口令落盘在同一个 `commit()` 里**，中途断电不会出现「码废了、口令也没设上」的死锁
- **恢复码的错误计数与口令完全独立**，孩子乱输恢复码不会把家长的日常口令一起锁死
- **恢复成功即家长接管**：当前会话按「已结束」处理，不保留剩余时间

## 为什么是 8 位数字，不是字母码

遥控器十字键一次按键只能表达 5 个选项（约 2.3 bit），而一位十进制要 3.3 bit——D-pad 输入的理论下限就是约 1.5 次/位。现有的 3×4 数字网格平均 2.14 次/位，已经贴着下限；换成 32 键字母网格反而更贵（3.9 次/位）。

**能省的只有码长。** 8 位有效空间 1e7，配合「错 5 次锁 30 分钟」，穷举期望约 114 年，比 6 位口令还强 10 倍。

校验位用 Verhoeff 而非 Luhn：Luhn 对 `0↔9` 的相邻对调是盲的（自检里 2000 次随机对调漏检 51 次），Verhoeff 对单点错误和所有相邻对调都是 100%。

## 升级与安装

**从 1.0.0 升级**：直接覆盖安装即可，口令、时长等设置都保留。但 1.0.0 的实例没有恢复码，装好后请到设置页的「恢复码」行生成一次。

**全新安装**：设口令时会引导你保存恢复码。

```bash
adb install -r quizgate-1.1.0.apk
```

**别忘了两条授权**（小米电视固件没有 UI 入口）：

```bash
adb shell appops set app.quizgate.tv SYSTEM_ALERT_WINDOW allow
adb shell cmd notification allow_listener app.quizgate.tv/app.quizgate.tv.NotifProbe
```

## 实测记录

这一版新增了第二台设备的实测证据（`evidence/D2-2026-11-10/`），覆盖：两个恢复码入口、旧码重放被拒、校验位单点改错提示、成功后落盘一致性。

1.0.0 的四条核心结论仍然成立，均有原始输出：

- 按 HOME 不逃逸，遮罩保持焦点
- 按电源键被 `killAllThirdApp` 强停，通知监听 150ms 内把进程拉回
- 重启后会话按快照自动接续
- 熄屏期间不扣时，且遮罩不会把电视点亮

## 已知限制

- 恢复码照片和口令**同时**丢失，仍然只能卸载重装（应用内看不到已生成的码，这是刻意的）
- 防不住卸载——这是 Android 的设计
- 目前只在小米电视 MiTV-MFTR0（Android 11）上验证过，见 [兼容性矩阵](../docs/compatibility.md)
- 遮罩期间不暂停下层音频
- 题库每年级 8 题（共 72 题）+ 口算兜底，只够验证流程
